# Zomato Restaurant Analytics and Recommendation System

## Overview
An exploratory data analysis and machine learning project focused on understanding restaurant characteristics, customer reviews, ratings, pricing, and cuisine patterns.

## Project Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering and selection
- Customer review sentiment analysis
- K-Means clustering
- Agglomerative Hierarchical Clustering
- Model evaluation and comparison
- Saved machine learning model for future predictions

## Machine Learning
The K-Means clustering model was selected for deployment preparation because it supports predictions on unseen restaurant records.

The trained model and preprocessing pipeline are saved in Joblib format.

## Project Structure
- notebooks/: Analysis and model development notebook
- models/: Trained machine learning model
- app/: Future Streamlit application
- requirements.txt: Python dependencies

## Installation
1. Clone this repository.
2. Create a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt
